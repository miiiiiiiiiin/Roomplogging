# 🧹 방구석 플로깅

**[만들래 10분 게임 콘테스트 – 방치편] 출품작**

방을 떠나지 않는 은둔자의 각성 이야기  
**슬라임 처치 기반 스토리 게임**입니다.

플레이 링크: https://mandlemandle.com/project/ff67dd/game

---

## 🎮 게임 소개

방에서 한 발자국도 나오지 않는 히키코모리 주인공.  
어느 날, 쓰레기통에서 태어난 **정체불명의 괴생명체**에게 습격당합니다.

목숨까지 위협받는 상황 속에서  
주인공은 결국 괴생명체에게 맞서 싸우게 됩니다.

과연 주인공은 **자신과 자신의 방**을 지켜낼 수 있을까요?

---

## 🧠 세계관 & 콘셉트

**플로깅(Plogging)**이란  
조깅을 하며 쓰레기를 줍는 운동을 뜻합니다.

하지만 이 게임의 주인공은  
자신의 영역 밖으로는 절대 나가지 않는 은둔자입니다.  
부모님의 말조차 듣지 않습니다.

그런 주인공을 가만히 둘 수 없었던  
**정체를 알 수 없는 그림자**는  
주인공을 각성시키기 위해  
강제로 **‘방구석 플로깅’**을 시작하게 만듭니다.

방 청소와 생존이 맞물린 상황 속에서,  
주인공은 선택의 기로에 놓이게 됩니다.

## 🧺 제작 의도

방을 오랫동안 어질러 둔 상태를  
**‘방치’**라는 키워드로 해석해  
이번 콘테스트 주제에 맞춰 제작했습니다.

일상적인 공간인 ‘방’을 배경으로,  
청소와 생존이라는 다소 극단적인 대비를 통해  
가볍지만 메시지를 담은 이야기를 전하고자 했습니다.
